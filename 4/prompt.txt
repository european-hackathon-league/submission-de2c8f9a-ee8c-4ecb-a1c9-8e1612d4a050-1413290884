Create a standalone TypeScript data pipeline script that ingests raw BMW customer feedback Excel/CSV files, cleans and sanitizes the records, enriches them with aspect-based sentiment analysis and vector embeddings using OpenAI APIs, and publishes the structured data into a Neon PostgreSQL database (with `pgvector`).

The database schema must be designed so a downstream Next.js application can seamlessly query aggregate metrics for UI dashboards and perform hybrid semantic vector searches for LLM/RAG workflows. 

## Data Input Characteristics & Sanitization Rules

- Input files are inside data/feedbacks  (csv)
- Normalize CSV header names to standard `snake_case` (e.g., `Feedback\_Explorer ID` -> `feedback_explorer_id`, `Derivate (e-code)` -> `derivate_code`, `Sales Description` -> `sales_description`) 
- Data cleaning:
    - Trim whitespace from string fields
    - Filter out invalid or near-empty customer verbatims (e.g., empty string, `< 5` characters, or placeholder values like `"N/A"`, `"None"`).

## Database Schema Specification (Neon PostgreSQL)

Generate migration scripts or Drizzle schema definitions for two primary tables:

### 1. `feedback_entries` (Parent Record)
- `id`: `UUID` (Primary Key, default `gen_random_uuid()`)
- `feedback_explorer_id`: `TEXT` (Unique)
- `brand`: `TEXT`
- `sales_description`: `TEXT`
- `country`: `TEXT`
- `derivate_code`: `TEXT` (e.g., 'F70', 'G60', 'G70')
- `engine_type`: `TEXT` (e.g., 'BEV', 'PHEV', 'ICE')
- `feedback_type`: `TEXT`
- `raw_feedback`: `TEXT` (Original customer verbatim)
- `translated_feedback`: `TEXT` (English translation generated by OpenAI if original is non-English)
- `embedding`: `vector(1536)` (OpenAI `text-embedding-3-small` embedding of the verbatim)
- `created_at`: `TIMESTAMPTZ` (default `NOW()`)

### 2. `feedback_aspects` (Child 1:N Record)
- `id`: `UUID` (Primary Key, default `gen_random_uuid()`)
- `feedback_entry_id`: `UUID` (Foreign Key referencing `feedback_entries.id` with `ON DELETE CASCADE`)
- `vfc_category`: `TEXT` (e.g., 'Infotainment', 'ADAS / Driving Assistance', 'Climate Control', 'Seats / Comfort', 'Powertrain')
- `aspect_term`: `TEXT` (e.g., 'Touchscreen Lag', 'Highway Assistant', 'Seat Ventilation')
- `quote_snippet`: `TEXT` (Sub-string quote from verbatim supporting this aspect)
- `sentiment`: `TEXT` ('Positive', 'Negative', 'Neutral')
- `sentiment_score`: `NUMERIC(3, 2)` (Scale from -1.00 to +1.00)
- `created_at`: `TIMESTAMPTZ` (default `NOW()`)

Include indexes for fast filtering on `(derivate_code, engine_type)`, `(vfc_category, sentiment)`, and an HNSW index on `feedback_entries.embedding` (`vector_cosine_ops`)
