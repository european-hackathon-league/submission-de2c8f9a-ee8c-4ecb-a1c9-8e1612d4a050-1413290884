19: _Avoid_: Origin, provider

35: ### Aspects
36: 
37: **Aspect**:
38: One thing a feedback says about one part of the vehicle. A feedback has zero or more aspects, and each one carries its own feedback type, buckets, and sentiment.
39: _Avoid_: Topic, tag, label, mention
40: 
41: **Feedback Type**:
42: The source system's own classification of an aspect: Likes, Difficult to Use, Wants, or Defect. It belongs to the aspect, so one feedback can be both Likes and Defect.
43: _Avoid_: Feedback category, kind
44: 
45: **VFC Label**:
46: A curated, human-assigned classification from BMW's VFC taxonomy, made of an aspect term and an aspect label.
47: _Avoid_: Tag, annotation, class
48: 
49: **Aspect Term**:
50: The VFC level-2 name: the specific component or feature being discussed, e.g. "Touch screen, operation".
51: _Avoid_: Level 2, component, feature, subcategory
52: 
53: **Aspect Label**:
54: The VFC level-3 name: what was said about the aspect term, e.g. "Not user-friendly".
55: _Avoid_: Level 3, problem, finding
56: 
57: **Unlabelled Feedback**:
58: A feedback with no usable VFC label (blank or "no_class_found"). Its aspects can only be inferred.
59: _Avoid_: Unclassified feedback, uncategorised

61: ### Buckets
62: 
63: **VFC Category**:
64: One of 16 coarse buckets an aspect term belongs to, e.g. "Infotainment & Connectivity". Each aspect term maps to exactly one.
65: _Avoid_: Category group, area, domain, system
66: 
67: **Issue Type**:
68: One of 11 coarse buckets saying what kind of thing an aspect is, e.g. Malfunction, Usability Difficulty, Feature Request, Praise. Each aspect label maps to exactly one.
69: _Avoid_: Problem type, complaint type, defect type
70: 
71: **Unclassified**:
72: The bucket used when no VFC category or issue type fits. It is a bucket value, not a missing label: a labelled aspect can be Unclassified, and an unlabelled feedback can produce aspects that are not.
73: _Avoid_: Other, misc, unknown
74: 
75: **Taxonomy Mapping**:
76: The reviewed list assigning every aspect term to a VFC category and every aspect label to an issue type. It is the single place a bucketing decision is made or corrected.
77: _Avoid_: Classification, lookup, ontology
78: 
79: ### Provenance
80: 
81: **Curated Aspect**:
82: An aspect taken from a VFC label assigned by a human.
83: _Avoid_: Labelled aspect, ground truth
84: 
85: **Inferred Aspect**:
86: An aspect a model extracted from the verbatim of an unlabelled feedback, constrained to the same VFC categories and issue types.
87: _Avoid_: Predicted aspect, AI aspect, synthetic aspect
88: 
89: **Quote**:
90: The exact passage of the verbatim that supports an inferred aspect. Curated aspects have none.
91: _Avoid_: Snippet, excerpt, evidence

94: 
95: **Sentiment**:
96: Whether an aspect is Positive, Negative, or Neutral, decided by its issue type alone: Praise is Positive; Feature Request and Unclassified are Neutral; every other issue type is Negative.
97: _Avoid_: Polarity, tone, mood
98:

100: How strongly the customer expresses an aspect, from 0 to 1, regardless of direction.
101: _Avoid_: Strength, confidence, magnitude

104: Intensity signed by sentiment, from −1 to +1; always 0 for Neutral aspects. It ranks aspects within a sentiment; it never decides the sentiment.
105: _Avoid_: Rating, score, NPS
